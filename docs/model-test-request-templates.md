# 模型测试全局请求模板

入口：供应商的「模型测试」弹窗 →「请求预设」→「管理全局模板」。模型列表和模型映射测试共用此功能。

- 请求头和请求体分别选择预设、点击「应用」，只替换对应编辑框，不会自动发送请求。
- 内置默认预设继续使用当前端点的默认测试请求。
- 编辑框上方的「+」可将当前请求存为全局模板；管理窗口中可新增、重命名、编辑、删除模板。
- 模板保存在服务端，跨供应商、模型、浏览器共享。模板管理按请求头、请求体分组。
- 每个模板可以指定端点格式，也可以适用于所有格式。应用列表仅显示当前格式及通用模板；管理窗口显示全部模板。
- 切换端点、加载模板、保存模板不会自动覆盖正在编辑的测试请求。

## 当前模型占位符

请求体的顶层 `model` 支持 `"{{model}}"`，或直接省略该字段。应用时填入当前测试模型（优先使用已选模型映射）：

```json
{
  "model": "{{model}}",
  "input": "请简短介绍你自己。",
  "stream": true
}
```

固定的 `model` 字符串会原样保留。占位符仅处理请求体顶层 `model`，不会替换消息文本或请求头。从当前请求新建模板时，若 `model` 等于当前测试模型，会自动改为占位符。

请求头示例：

```json
{
  "X-Test-Scenario": "smoke"
}
```

模板对所有管理员可见，不应保存 API Key、Cookie 等敏感信息；后端仍按原有规则处理鉴权和必要系统头。

## 存储与校验

复用管理员系统配置 API，配置键为 `model_test_request_templates`，值为：

```json
{
  "headers": [],
  "body": [
    {
      "id": "example-body-template",
      "name": "Responses 简短问答",
      "api_format": "openai:responses",
      "content": { "model": "{{model}}", "input": "Hello", "stream": true }
    }
  ]
}
```

`api_format: null` 表示所有格式。每类最多 100 个模板，名称最长 100 个字符且同类不重复，总大小最多 1 MiB。内容必须为 JSON 对象；请求头还校验 HTTP 名称和字符串、数字、布尔值。加载失败会禁用模板维护并提供重试，默认请求及手动测试仍可用。保存前重新读取服务端列表，保留其他模板及另一分组的数据。

不需要新环境变量、数据表或数据库迁移。
